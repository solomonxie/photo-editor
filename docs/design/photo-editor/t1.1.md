# T1.1 Edit document & ops

The non-destructive model. Pure Swift with no UIKit/CI imports, so it's unit-testable.

```
EditDocument (Codable, Sendable, value type)
├── schemaVersion: Int
├── source: { filename, pixelSize, orientation, colorSpace }
├── patches: [PatchOp]          ← AI results: asset + optional brush mask
├── heal:    [BrushStroke]       ← source-normalized strokes
├── redEye:  Bool
├── reshape: ReshapeSpec         ← face/body sliders + manual warps
├── crop:    CropSpec            ← normalized rect, angle, quarter turns, flip
├── adjust:  AdjustValues        ← 13 sliders + auto flag
├── filter:  FilterRef?          ← { id, intensity }
├── smoothSkin: Double
├── cutout:  CutoutSpec?         ← subjects + background mode
└── layers:  [Layer]             ← index 0 = back; photo base implicit
      Layer { id, content, center, width, rotation, opacity, isHidden }
      content: text(TextSpec) | emoji(String) | image(asset, aspect)
```

Render order (fixed, not user-reorderable):

```
source → AI patches → heal → red eye → reshape warp → crop/rotate
       → adjust → filter → smooth skin → cutout bg → layers (back→front)
```

Why a fixed pipeline, not a free-form op list:
- Photos-style predictability. The slider result doesn't depend on history order.
- The graph is a stable shape, so `CIContext` can cache it and only the changed parameters recompute.
- Layers are the only user-ordered part.

## Rules

- Every case is declared now, even ones whose renderer lands later. Unknown
  or unimplemented kinds render as pass-through.
- Bitmaps are never inline. They're `assets/<uuid>.png` referenced by name.
  Brush masks are stored as strokes and rasterized at render size.
- Normalized coordinates (0–1) everywhere, so the proxy and full-res share one document.
- Undo/redo: a stack of `EditDocument` snapshots (cheap value copies), capped at 100.
  `beginGesture` / `endGesture` fold a slider drag into one step.
- Decode tolerates a newer `schemaVersion` by ignoring unknown keys. Migrations are keyed by version.

## Tests

- Round-trip encode/decode.
- Undo/redo across a coalesced gesture.
- An unknown layer kind survives a round-trip.
